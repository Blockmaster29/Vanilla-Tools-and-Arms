Feel the lack of tools and weapons in Minecraft?

This Mod will fix it!

# Dagger
- High Attack Speed
- Doesn't need a crafting table to be crafted
- Decreased Attack Range
- No Sweep Attack

# Battle Axe
- Heavy Weapon
- High Damage
- Slow Attack Speed
- Can be used like a normal axe
- Netherite Version can one shot normal mobs with a crit

# Spear
- A bit like a sword
- Increased Attack Range
- No Sweep Attack
- Can be thrown like a trident
- Works with loyalty enchantment
